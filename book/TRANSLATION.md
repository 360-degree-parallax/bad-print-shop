# 오이디푸스 왕 · 한국어 중역

- 저자: 소포클레스.
- 영문 저본: Francis Storr, 1912, Oedipus the King.
- 공개 원문: https://www.gutenberg.org/ebooks/31
- 본문 언어: 한국어. 이 사이트를 위해 새로 작성한 번역.

고대 그리스어에서 직접 옮긴 번역이 아니라 공개 영문 완역을 대조하여 한국어로 옮긴 중역이다. 시중의 한국어 번역본을 복제하지 않았다. 대사 437개와 첫 무대 지시를 포함한다. 시 형식의 대사와 합창은 연속된 산문으로 옮겼으며 정가·반정가와 무대 지시는 본문에 남겼다. 고유명사 표기와 문장부호는 한국어 표기로 정리했다. 저본이 410번째 발화의 화자를 CREON으로 표시한 곳은, 크레온의 입장을 알리는 합창대의 발화로 표기했다.

번역은 AI가 작성했다. 학술적으로 교감한 고대 그리스어 정본 번역은 아니다. 기존 시연용 다국어 재작성 문장은 제거했다.

화면의 각주 번호는 클릭 가능한 문장의 순번이다. 각주에서 연결되는 ‘대사 번호’는 이 저본에서 추출한 발화 순번이며, 고대 그리스어 원전의 행 번호가 아니다. 같은 발화에 속한 여러 문장은 같은 대사 번호를 공유한다.

- content.js: 화면 수집용 문장과 출처 메타데이터.
- oedipus-ko.txt: 읽고 대조할 수 있는 한국어 본문 전체.
