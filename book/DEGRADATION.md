# 압축 손실 (1차–20차)

번역도, 다시 쓰기도 아니다. 문장을 다시 저장할 때마다 한글 자모 단위로 정보가 깎인다.
이미지가 JPEG로 재저장될수록 세부 → 색 → 형태 순으로 무너지듯(히토 슈타이얼의 '빈곤한 이미지'),
글자는 받침 → 거센소리 → 겹모음 → 띄어쓰기 → 모음 → 자음 → 블록 → 판독 불가 순으로 무너진다.

`content-gen.js`의 `rows[i]`는 `BookText[i]`를 1~20번 다시 저장한 것이다. 본문 1,306문장 뒤에 개요 5문장(`wiki.js`의 `overview`)이 같은 규칙으로 이어진다. 생성: `node tools/compress.mjs`.

개요의 마지막 문장에 있는 `{n}`은 손실을 입지 않고, 화면에서 현재 "원문 일치" 수로 바뀐다. 문장이 무너져도 숫자만은 또렷하게 남는다. 포스터에는 가져간 순간의 숫자가 찍힌다.

## 규칙

각 음절은 문장 번호와 위치로 정해진 고정 난수를 가진다. 손실마다 문턱이 정해진 구간에서 곧게 올라가고, 내려가지 않는다. 한 번 잃은 정보는 다음 단계에서 돌아오지 않는다.

| 손실 | 내용 | 시작 → 최대 (차) | 최대 비율 |
|---|---|---|---|
| 받침 단순화 | 겹받침·거센 받침 → 홑받침 (끓 → 끌) | 1 → 4 | 전부 |
| 받침 탈락 | 받침이 떨어진다 (듯 → 드) | 1 → 10 | 전부 |
| 첫소리 평음화 | 된소리·거센소리 → 예사소리 (파 → 바) | 1 → 8 | 전부 |
| 겹모음 단순화 | ㅐ → ㅔ, ㅕ → ㅓ, ㅘ → ㅏ … | 3 → 10 | 전부 |
| 쉼표 탈락 | | 4 → 7 | 전부 |
| 띄어쓰기 압축 | 공백이 사라진다 | 5 → 16 | 95% |
| 모음 3단계 양자화 | ㅏㅓ → ㅏ, ㅗㅜㅡ → ㅡ, ㅔㅣ → ㅣ | 8 → 15 | 전부 |
| 자음 뭉개기 | 소리 나는 자리로 (ㅂ → ㅁ, ㄷㄹ → ㄴ, ㅅㅈㅎ → ㅇ) | 9 → 17 | 90% |
| 블록 현상 | 네 칸이 첫 글자로 칠해진다 (머리를 → 마리리리) | 10 → 19 | 50% |
| 판독 불가 | 아래 여덟 가지 중 하나 | 9 → 20 | 70% |

대략 1~8차는 읽히고, 9~14차에는 판독 불가가 섞이기 시작하며, 15~20차에는 노이즈가 된다.

## 판독 불가의 여덟 가지

자리마다 망가지는 방식이 정해져 있어서, 한 번 깨진 칸은 이후 단계에서도 같은 모양으로 남는다.

| 비율 | 모양 | 원인 |
|---|---|---|
| 18% | `?` | 대체 문자 |
| 18% | `■` | 검은 네모, 가림 |
| 10% | `□` | 글꼴에 글리프가 없음 (두부) |
| 10% | `�` | 깨진 바이트 |
| 16% | `諛`, `遺`, `瑜` … | UTF-8 바이트를 CP949로 읽음 |
| 10% | `ì»`, `ë¼` … | UTF-8 바이트를 CP1252로 읽음 |
| 15% | `늤`, `돆` … | 비트 하나가 뒤집혀 이웃 음절이 됨 |
| 3% | `&#45796;` | 이스케이프된 채 남음 |

## 반드시 잃는다

저장할 때마다 무언가 잃어야 한다. 이번 단계에서 깎을 것이 없는 문장은 다음 단계의 손실을 앞당긴다. 20차의 손실까지 다 일어난 짧은 문장은 뒤에서부터 한 칸씩 판독 불가가 되고, 그다음에는 길이가 줄어든다. 마지막 한 칸은 � → □ → ■ 로 꺼지고, 그 뒤로는 더 잃을 것이 없다. "아, 아!" 같은 아주 짧은 문장은 8차쯤 "■!"에 이르러 거기서 멈춘다.

## 건드리지 않는 것

화자 표시("오이디푸스: ")와 〈첫째 정가〉 같은 합창 표지는 문서의 구조라서 남긴다. 인물 링크와 "원문 일치" 개수가 그대로 작동한다. 무대 지시의 〈 〉 괄호와 문장 끝 부호도 남는다.

## 이미 유통 중인 사본

본문 1,306문장 가운데 123문장(약 10%)은 처음부터 5차(37), 10차(34), 15차(52) 사본으로 열린다. 앞서 다녀간 누군가가 이미 가져갔던 문장이다. 이 문장들은 처음부터 "원문 일치"에서 빠지므로 첫 화면의 숫자는 1,183이다. 가져가면 그 단계에서부터 이어서 무너지고, 20차까지 남은 횟수만큼만 움직인다(15차 사본은 다섯 번). 어느 문장이 몇 차로 시작하는지는 문장 번호로 정해지며 `content-gen.js`의 `start`에 있다.
