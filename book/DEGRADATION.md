# 압축 손실 (1차–7차)

번역도, 다시 쓰기도 아니다. 문장을 다시 저장할 때마다 한글 자모 단위로 정보가 깎인다.
이미지가 JPEG로 재저장될수록 세부 → 색 → 형태 순으로 무너지듯(히토 슈타이얼의 '빈곤한 이미지'),
글자는 받침 → 거센소리 → 겹모음 → 띄어쓰기 → 모음 → 자음 → 블록 순으로 무너진다.

`content-gen.js`의 `rows[i]`는 `BookText[i]`를 1~7번 다시 저장한 것이다. 생성: `node tools/compress.mjs`.

## 규칙

각 음절은 문장 번호와 위치로 정해진 고정 난수를 가진다. 단계마다 손실 종류별 문턱이 올라가기만 하므로, 한 번 잃은 정보는 다음 단계에서 돌아오지 않는다.

| 손실 | 내용 | 1차 | 2차 | 3차 | 4차 | 5차 | 6차 | 7차 |
|---|---|---|---|---|---|---|---|---|
| 받침 단순화 | 겹받침·거센 받침 → 홑받침 (끓 → 끌) | 35% | 70% | 전부 | | | | |
| 받침 탈락 | 받침이 떨어진다 (듯 → 드) | 12% | 30% | 50% | 70% | 85% | 전부 | |
| 첫소리 평음화 | 된소리·거센소리 → 예사소리 (파 → 바) | 10% | 35% | 65% | 90% | 전부 | | |
| 겹모음 단순화 | ㅐ → ㅔ, ㅕ → ㅓ, ㅘ → ㅏ … | | 20% | 45% | 75% | 전부 | | |
| 띄어쓰기 압축 | 공백이 사라진다 | | | 15% | 35% | 55% | 75% | 90% |
| 쉼표 탈락 | | | | 50% | 전부 | | | |
| 모음 3단계 양자화 | ㅏㅓ → ㅏ, ㅗㅜㅡ → ㅡ, ㅔㅣ → ㅣ | | | | 20% | 45% | 75% | 전부 |
| 자음 뭉개기 | 소리 나는 자리로 (ㅂ → ㅁ, ㄷㄹ → ㄴ, ㅅㅈㅎ → ㅇ) | | | | | 25% | 55% | 85% |
| 블록 현상 | 네 칸이 첫 글자로 칠해진다 (머리를 → 마리리리) | | | | | 10% | 25% | 45% |
| 판독 불가 | 음절이 `?`가 된다 | | | | | | 4% | 12% |

## 반드시 잃는다

앞 단계와 같은 문장이 나오면 이미 시작된 손실의 문턱을 조금씩 더 민다. 더 깎을 것이 없는 짧은 문장은 뒤에서부터 한 칸씩 `?`가 되고, 다 지워지면 길이가 줄어든다. 최소 한 칸은 남아서 누를 수 있다. "아, 아!", "말하라!" 같은 아주 짧은 문장은 5~6차에 부호만 남고, 그 뒤로는 더 잃을 것이 없다.

## 건드리지 않는 것

화자 표시("오이디푸스: ")와 〈첫째 정가〉 같은 합창 표지는 문서의 구조라서 남긴다. 인물 링크와 "원문 일치" 개수가 그대로 작동한다. 무대 지시의 〈 〉 괄호와 문장 끝 부호도 남는다.
