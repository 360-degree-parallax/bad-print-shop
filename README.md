# 불량 인쇄소 · BAD PRINT SHOP

문장을 수집해 왜곡된 필사 포스터를 만드는 브라우저 작업실.

## 사용

왼쪽은 위키 문서 형식의 《오이디푸스 왕》입니다. 문장 위에 커서를 올리면 검게 선택되고, 누르면 오른쪽 포스터로 옮겨집니다. 길게 누르면 왜곡 형태가 바뀝니다. 메뉴는 없습니다. 영수증 꼬리는 처음부터 오른쪽 아래 모서리에 나와 있습니다(앞 손님 영수증이 찢겨 나간 끝자락과 내 영수증 머리). 꼬리를 누르거나 문서 끝까지 내려가면 꼬리가 다시 들어가고, 화면 아래 가운데에서 롤 전체(앞 손님 두 장 + 내 영수증)가 위로 출력된 뒤 잘립니다. 잘린 영수증은 휠·드래그·터치로 끝까지 훑어볼 수 있습니다. 쉼표(,) 키로 크기·너비·풍화 설정을 엽니다. 화면은 검은 바탕에 흰 글자뿐이고, 공간은 위치로만 나뉩니다.

본문 사이의 픽셀 이미지 20장은 `images/01.png`~`images/20.png`에 넣으면 표시됩니다. 미드저니 프롬프트는 [images/PROMPTS.md](images/PROMPTS.md)에 있습니다. 문서 구조와 이미지 위치는 `wiki.js`에서 바꿉니다.

## 공개 페이지 설정

Settings → Pages → Source: Deploy from a branch → Branch: main → Folder: /(root) → Save.

배포 후 주소: https://360-degree-parallax.github.io/bad-print-shop/

## 실행

index.html을 브라우저에서 열면 실행됩니다. HTML/CSS/JavaScript/Canvas로 구성하며 빌드나 API 연결이 필요 없습니다. 새로고침하면 수집 내역이 초기화됩니다.

## 본문과 글꼴

본문은 소포클레스 《오이디푸스 왕》의 한국어 중역 전문입니다. 프랜시스 스토어의 1912년 공개 영문 완역을 대조해 이 사이트용으로 새로 옮겼습니다. 437개 대사와 첫 무대 지시를 포함하며 1,306개의 클릭 가능한 문장으로 구성했습니다. 고대 그리스어에서 직접 번역한 학술 정본은 아닙니다.

번역 출처와 표기 원칙: [book/TRANSLATION.md](book/TRANSLATION.md)
한국어 본문 전체: [book/oedipus-ko.txt](book/oedipus-ko.txt)

드림흐물체 파생 글꼴과 Pretendard의 저작권·라이선스는 assets의 문서를 참조하세요. 코드에는 별도의 오픈소스 라이선스를 부여하지 않았습니다.

## 가져간 문장의 손실

문장을 하나 가져갈 때마다 문서에 남은 그 문장은 한 번 더 "다시 저장"되어 압축 손실을 입습니다. 받침 → 거센소리 → 겹모음 → 띄어쓰기 → 모음 → 자음 → 블록 → 판독 불가 순으로 무너지며, 1~20차까지 한 번 잃은 정보는 돌아오지 않고, 끝에는 ■·□·�·글자 깨짐 같은 판독 불가가 남습니다. 전문 1,306문장의 20단계는 `content-gen.js`에 있고 `node tools/compress.mjs`로 다시 만들 수 있습니다. 규칙과 단계별 비율: [book/DEGRADATION.md](book/DEGRADATION.md)

## 배포 후 캐시

`index.html`의 CSS·JS 주소에는 `?v=<빌드>`가 붙어 있습니다. 파일을 고친 뒤 `sh tools/stamp.sh`를 실행하고 커밋하면, 예전 파일을 캐시한 휴대폰과 브라우저도 다음 접속 때 새 파일을 받습니다. 빌드가 바뀌면 브라우저에 저장된 "가져간 횟수"도 한 번 초기화됩니다.

## 좌측 서체

좌측 위키 문서는 도스고딕(DOSGothic, © Damheo Lee, MIT, `assets/DOSGothic-LICENSE.txt`)을 16px 배수로만 씁니다. 용량을 줄이려고 페이지에 나오는 글자만 남긴 `assets/DOSGothic-subset.woff`(약 74KB)를 씁니다. `content-gen.js`를 다시 만들면 `python3 tools/subset-dosgothic.py <원본 DOSGothic.ttf>`로 서브셋도 다시 만드세요.

## 각주

대사 번호를 누르면 뜨는 각주는 `footnotes.js`가 대사마다 하나씩 만듭니다. 대사 안의 낱말에서 시작해, 사실인 서지 정보(1912년 스토어 번역, 『꿈의 해석』, 라우렌치아나 사본 등)와 존재하지 않는 판본·스캔·독서 카드가 같은 말투로 섞입니다. 실존 인물의 말을 지어내 인용하지는 않습니다. 같은 대사에는 언제나 같은 각주가 나옵니다(438개 모두 다름). 각주 문구를 고치면 `python3 tools/subset-dosgothic.py <원본 DOSGothic.ttf>`로 글꼴 서브셋도 다시 만드세요.
